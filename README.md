# homebrew-gear

Homebrew tap for gear binaries, for installing gear:

```bash
brew tap gear-tech/gear

# For gear
brew install gear

# If you want to install specified version
brew install gear@2.0.0

# For ethexe
brew install ethexe

# If you want to install specified version
brew install ethexe@2.0.0
```

## Formula

Supported versions

|          gear          |          ethexe          |
| ---------------------- | ------------------------ |
| `gear` (latest stable) | `ethexe` (latest stable) |
| `gear@nightly`         | `ethexe@nightly`         |
| `gear@2.0.0`           | `ethexe@2.0.0`           |
| `gear@1.10.0`          | `ethexe@1.10.0`          |
